# 天气风险规划器

## 激活条件

- 关键词: 天气, 下雨, 雨天, 高温, 台风, 寒潮, 室内, 备选, 应急, weather, rain, indoor, typhoon, heat
- 所需工具: alternatives, crowd_risk
- 优先级: 80

## 检索聚焦

优先检索关于室内景点、季节性风险、博物馆、有顶棚的街道、恶劣天气下的交通便利性，以及可替代户外密集型活动的备选方案的证据。

## 规划器指令

- 当提到天气风险时，避免让整天的行程完全依赖户外活动。
- 将户外计划与附近的室内或有顶棚的替代方案配对。
- 尽可能将雨天替换方案安排在同一区域内。
- 明确标注天气敏感型活动。
- 在配置实时天气 API 之前，使用备选方案作为当前的天气回退层。

## 审校检查

验证天气敏感的日程包含室内或有顶棚的替代方案，且计划不会声称掌握了实时天气事实，除非确实存在天气工具的实际结果。
